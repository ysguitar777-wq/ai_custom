# Claude アプリ(claude.ai / Claude Code)への適用ガイド

API 向けキット(`config/`・`examples/`)とは別に、**Claude アプリ本体で Sonnet を使うとき**に Fable 的な挙動へ近づけるための設定です。

## アプリでできること・できないこと

| レバー | アプリで使えるか | 備考 |
|---|---|---|
| Fable スタイルの挙動指示(プロンプト) | ◯ | 本ディレクトリの貼り付け用テキストを使う |
| モデル選択(Sonnet + 拡張思考) | ◯ | モデルピッカー / Claude Code の `/model` |
| `effort: "xhigh"` などの API パラメータ | ✕ | アプリ内部の API 呼び出しは変更不可 |
| Advisor ツール / Task Budget | ✕ | API 直接利用時のみ |

つまりアプリで埋められるのは「挙動・スタイルのギャップ」で、「思考の深さの上限」はアプリの設定に依存します(拡張思考を ON にするのが上限)。

## 適用手順

### claude.ai(Web / デスクトップ / モバイル)

1. **全チャット共通にする場合**: 設定 → プロファイル → 「Claude への指示(preferences)」に `paste_claude_ai.md` の内容を貼り付け
2. **特定プロジェクトだけの場合**: プロジェクト → 「指示を設定」に同じ内容を貼り付け(こちらの方が確実に反映されます)
3. モデルピッカーで Sonnet を選択し、拡張思考を有効にする

### Claude Code

1. リポジトリ直下の `CLAUDE.md` が自動で読み込まれます(このリポジトリには設定済み)
2. 全プロジェクト共通にしたい場合は `~/.claude/CLAUDE.md` に同じ内容をコピー
3. `/model` で Sonnet を選択(Claude Code は effort を内部で高めに管理するため、指示側の調整だけで十分です)

## 注意

- Sonnet 5 は指示を**字義通り**に守ります。強すぎる命令調(「絶対に〜せよ」)は過剰発火するので、貼り付けテキストのトーンのまま使ってください。
- アプリには元々システムプロンプトがあり、この指示はそれに**追加**されます。アプリの標準挙動と矛盾する指示(出力形式の強制など)は効きにくいことがあります。
- 効果はタスク依存です。1〜2 週間使ってみて、不要なブロックは削ってください。
